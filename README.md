# TWBD Movie Finder

Небольшое веб-приложение на чистом HTML/CSS/JS, которое обращается к [TMDB API](https://www.themoviedb.org/documentation/api) и показывает популярные фильмы с возможностью поиска.

## Возможности

- Список популярных фильмов при загрузке страницы
- Поиск фильмов по названию
- Постер, год выхода и рейтинг для каждого фильма

## Запуск

Файлы статические, серверная сборка не нужна. Достаточно открыть `index.html` в браузере или поднять локальный сервер, например:

```bash
npx serve .
```

## Технологии

- Vanilla JavaScript (fetch API)
- CSS Grid для адаптивной сетки карточек

## Примечание

Ключ TMDB API используется на клиенте и виден в исходном коде — это нормально для демо/учебного проекта, но для боевого продакшена рекомендуется проксировать запросы через бэкенд.
